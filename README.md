# 🇮🇹 Ripasso

> **망각과 떠올림을 위한 복습**

Ripasso는 이탈리아어로 **'복습(Review)'** 을 의미합니다.

망각곡선(Spaced Repetition)을 기반으로,  
단어와 예문, 발음을 자연스럽게 반복하며  
언어를 '외우는 것'이 아니라 **'다시 떠올리는 것'** 에 집중하는 언어 학습 플랫폼입니다.

https://ripasso-8a3bc.web.app/

## ✨ Features

- 🔐 Google 로그인
- 📚 플래시카드 기반 단어 학습
- 🧠 망각곡선 기반 복습 시스템
- ✍️ 예문 빈칸 퀴즈
